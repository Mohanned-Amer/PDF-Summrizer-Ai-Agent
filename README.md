📚 وكيل الذكاء الاصطناعي لتلخيص وتحليل ملفات PDF

هو مساعد تعليمي مدعوم بالذكاء الاصطناعي، مصمم لمساعدة الطلاب على فهم ومراجعة موادهم الدراسية باستخدام مستندات PDF.

وصف الملفات
main.py

الملف الرئيسي للتطبيق. يتحكم في سير عمل التطبيق، والمصادقة، وحالة الجلسة، والربط بين واجهة المستخدم ووظائف الذكاء الاصطناعي.

ui.py

يحتوي على مكونات واجهة المستخدم الخاصة بـ Streamlit، مثل صفحة تسجيل الدخول، والشريط الجانبي، وقسم رفع ملفات PDF، وواجهة الملخص والاختبار.

lang_helper.py

يحتوي على المنطق الرئيسي للتطبيق، بما في ذلك المصادقة، واستخراج النص من ملفات PDF، والتواصل مع الذكاء الاصطناعي، وإنشاء الملخصات والاختبارات، وإدارة المحادثات.

style.py

يحتوي على تنسيقات CSS المستخدمة لتحسين مظهر واجهة Streamlit.

db.json

ملف JSON محلي بسيط يُستخدم لتخزين حسابات المستخدمين وبيانات المحادثات.

requirements.txt

يحتوي على مكتبات Python المطلوبة لتشغيل المشروع.

🔑 مفتاح OpenRouter API

يستخدم التطبيق OpenRouter للتواصل مع نماذج الذكاء الاصطناعي.

قبل تشغيل التطبيق، يجب إعداد مفتاح API الخاص بك.

للتطوير المحلي، يمكنك إنشاء ملف باسم .env:

OPENROUTER_API_KEY=your_api_key_here


أما بالنسبة إلى Streamlit Community Cloud، فأضف مفتاح API من خلال إعدادات Secrets الخاصة بالتطبيق.

مثال:

OPENROUTER_API_KEY = "your_api_key_here"


«لا تقم أبدًا بنشر مفتاح API الحقيقي الخاص بك على GitHub.»

git clone https://


ثم انتقل إلى مجلد المشروع:

cd programming-ai-agent

2. إنشاء بيئة افتراضية
python -m venv venv

3. تفعيل البيئة

على نظام Windows:

venv\Scripts\activate

4. تثبيت المكتبات المطلوبة
pip install -r requirements.txt

ابدأ تشغيل تطبيق Streamlit باستخدام:

streamlit run main.py

⚠️ القيود
يدعم التطبيق حاليًا مستندات PDF فقط.
تعتمد جودة الملخص والأسئلة التي يتم إنشاؤها على جودة استخراج النص من ملف PDF وجودة استجابة الذكاء الاصطناعي.
قد لا يتم استخراج ملفات PDF الممسوحة ضوئيًا والتي تحتوي على صور دون نص قابل للتحديد بشكل صحيح.
تم تصميم التخزين المحلي باستخدام JSON لبيئة تعليمية أو لمشروع بسيط، وليس لنظام واسع النطاق مخصص للإنتاج.
